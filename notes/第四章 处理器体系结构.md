## Y86-64 顺序实现

### 指令执行框架

*   **取指**: 地址 PC 从指令内存读指令, PC 增加器计算 valP
    *   指令指示符字节(icode 和 ifun)
    *   寄存器指示符字节(rA 和 rB)
    *   八字节常数 valC
    *   下一地址 valP
*   **译码**: 寄存器文件读端口 A 和 B 同时读 valA 和 valB
*   **执行**: ALU 执行操作, 得到 valE
    *   简单加 0
    *   内存地址
    *   栈指针
    *   设置条件码 CC / 分支信号 Cnd
    *   检验条件码, 决定是否更新目标寄存器
*   **访存**:  写内存/读内存 valM
*   **写回**: 写寄存器文件, 端口 E 写 ALU 结果 valE, 端口 M 写数据内存值 valM
*   **更新 PC**: valP 下一指令地址/ valC 调用指令或跳转指令地址/ valM 返回地址

### SEQ时序

**SEQ = 组合逻辑 + 存储设备**

**组合逻辑**和**读存储器**看作瞬时

*   指令内存看作组合逻辑

**写存储器**需要**时钟控制**

*   PC 每周期更新
*   CC 整数运算更新
*   数据内存 `rmmovq` `pushq` `call` 更新
*   寄存器文件每周期可更新两个写端口 E/M

**原则: 从不回读**

不读该指令更新的状态

### SEQ 阶段实现

**取指**

PC 为地址取 10 个字节

*   Split = Byte0 = icode : ifun

    *   instr_valid 是否合法

        ```C
        bool instr_valid = icode in { IHALT, INOP, IRRMOVQ, IIRMOVQ, IRMMOVQ, IMRMOVQ, IOPQ, IJXX, ICALL, IRET, IPUSHQ, IPOPQ};
        ```

    *   need_regids: 是否有寄存器指示符字节

        ```C
        bool need_regids = icode in { IRRMOVQ, IOPQ, IPUSHQ, IPOPQ, IIRMOVQ, IRMMOVQ, IMRMOVQ };
        ```

    *   need_valC: 是否有常数字

        ```C
        bool need_valC = icode in { IIRMOVQ, IRMMOVQ, IMRMOVQ, IJXX, ICALL };
        ```

*   Align = Byte1-9

    ```C
    若 need_regids:
    	Byte1 = rA : rB
    
    若 need_valC:
    	有寄存器字节: Bytes2-9 = valC
        无寄存器字节: Bytes1-8 = valC
    ```

*   valP

    ```C
    word valP = PC + 1 + need_regids + 8 * need_valC;
    ```

*   imem_error: PC 不合法, icode : ifun = INOP : 0

*   instr_valid / imem_error 推迟到访存阶段组合为 Stat

寄存器文件: 2 读端口 + 2 写端口

```python
 	icode in { IRRMOVQ, IRMMOVQ, IOPQ, IPUSHQ } : rA;
    icode in { IPOPQ, IRET } : RRSP;

];
```

```python
# 读 B 端口: srcB -> valB

];
```

```python
    1 : RNONE;
];
```

```python
# 写 M 端口: dstM <- valM
```

```python

    	⬇
```

```python
word alufun = [
    icode == IOPQ : ifun;
    1 : ALUADD;
];
```

```python
word aluA = [
    icode in { IRRMOVQ, IOPQ } : valA;
    icode in { IIRMOVQ, IRMMOVQ, IMRMOVQ } : valC;
    icode in { ICALL, IPUSHQ } : -8;
    icode in { IRET, IPOPQ } : 8;
];
```

```python
word aluB = [
    icode in { IRMMOVQ, IMRMOVQ, IOPQ, ICALL, IPUSHQ, IRET, IPOPQ } : valB;
    icode in { IRRMOVQ, IIRMOVQ } : 0;
];
```

```python
bool set_cc = icode in { IOPQ };

ZF = (valE == 0)
SF = (valE < 0)
OF = 有符号溢出
```

```python
bool Cnd = [
    ifun == C_YES : 1;
    ifun == C_LE : (SF ^ OF) || ZF;
    ifun == C_L : SF ^ OF;
    ifun == C_E : ZF;
    ifun == C_NE : !ZF;
    ifun == C_GE : !(SF ^ OF);
    ifun == C_G : !(SF ^ OF) && !ZF;
    1 : 0;
];
```

### PIPE 各阶段实现

**PC 选择和取指**

预测

```python
word f_predPC = [
    f_icode in { IJXX, ICALL } : f_valC;
    1 : f_valP;
];
```

实际

```python
word f_pc = [
    M_icode == IJXX && !M_Cnd : M_valA;   // 分支预测错了
    W_icode == IRET : W_valM;             // ret 完成
    1 : F_predPC;                         // 默认:用上一周期预测的值
];
```

![PIPE PC更新和取指](../images/PIPE PC更新和取指.png)



**译码和写回**

转发

```python
word d_valA = [
    D_icode in { ICALL, IJXX } : D_valP;   # ① call/jXX 用 valP
    d_srcA == e_dstE : e_valE;             # ② 从执行阶段转发 valE
    d_srcA == M_dstM : m_valM;             # ③ 从访存阶段转发 valM
    d_srcA == M_dstE : M_valE;             # ④ 从访存阶段转发 valE
    d_srcA == W_dstM : W_valM;             # ⑤ 从写回阶段转发 valM
    d_srcA == W_dstE : W_valE;             # ⑥ 从写回阶段转发 valE
    1 : d_rvalA;                           # ⑦ 默认:寄存器文件读出值
];
```
