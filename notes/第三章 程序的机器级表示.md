# 第三章 程序的机器级表示

```bash
gcc -Og -S test.c	# 汇编代码 test.s
gcc -Og -c test.c	# 目标代码 test.o
gcc -Og -o test main.c test.c	# 可执行代码 test
```

```bash
objdump -d test.o	# 反汇编 test.s
```
