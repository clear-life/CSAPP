## 整数表示

无符号编码 = $\sum_{i=0}^{w-1} x_i 2^i$

补码编码 = $- x_{w-1} 2^{w-1} + \sum_{i=0}^{w-2} x_i 2^i$

$\left|TMin\right| = \left|TMax\right| + 1$

类型转换: 位不变, 解释方式改变

截断: 位长改变, 解释方式不变

零扩展: 高位添0

符号扩展: 添最高有效位

## 整数运算

**加法**

无符号加法: $(x + y)\mod 2^w \in [0, 2^w-1]$

补码加法: $(x + y)\mod 2^w \in [-2^{w-1}, 2^{w-1}-1]$

阿贝尔群: 模数加法, 集合 $A$ 和运算 $\cdot$ 满足: 

*   封闭性

*   交换律, 结合律

*   单位元

*   逆元

    *   无符号
        $$
        -x =
        \begin{cases}
        x, & x = 0 \\
        2^{w} - x, & x > 0
        \end{cases}
        $$

    *   有符号
        $$
        -x =
        \begin{cases}
        TMin_w, & x = TMin_w \\
        -x, & x > TMin_w
        \end{cases}
        $$

溢出检测

```C++
bool check_u(unsigned x, unsigned y)
{
    unsigned s = x + y;
    return s < x || s < y;
}

bool check_t(int x, int y)
{
    int s = x + y;
    return x > 0 && y > 0 && s <= 0 || x < 0 && y < 0 && s >= 0;
}
```

**乘法**

无符号乘法: $(x \times y)\mod 2^w \in [0, 2^w-1]$

补码乘法: $(x \times y)\mod 2^w \in [-2^{w-1}, 2^{w-1}-1]$

乘以2的幂 = 左移

除以2的幂

*   无符号 = 左移
*   补码 = `(x < 0 ? x + (1 << k) - 1 : x) >> k`

## 浮点数

**不满足结合律**

单精度

*   exp = 8 位
*   frac = 23 位

双精度

*   exp = 11 位
*   frac = 52 位

![浮点格式](../images/浮点格式.png)

$$
V = (-1)^s \times M \times 2^E
$$
规格化值
$$
E = exp - Bias \\
Bias = 2^{k-1} -1 \\
M = 1 + 0.frac
$$
非规格化值

>   0 与 接近 0 的数

$$
E = 1 - Bias \\
M = f
$$
