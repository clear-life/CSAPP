# 环境搭配

### wsl

担心 ubuntu 26.04 可能出问题, 故使用 ubuntu 24.04版本

```powershell
wsl --install -d Ubuntu-24.04
```

检验

```powershell
wsl -l -v
```

进入 wsl ubuntu

```powershell
wsl
```

更新

```bash
sudo apt-get update && sudo apt-get upgrade
```

### 32位支持

Data lab 需要 32 位编译支持

不然编译时会报错找不到 `bits/libc-header-start.h` 

```bash
sudo apt-get install gcc-multilib
```
